# 🎯 POPSHOT — 웹 FPS 에임 트레이너

브라우저에서 바로 하는 3D 에임 연습 게임입니다. 구체 · 풍선 타겟과 움직이는 사람 표적(트래킹)으로 플릭, 트래킹, 타겟 전환, 반응속도를 연습할 수 있습니다.
빌드 과정 없이 정적 파일만으로 동작합니다 (Three.js 포함).

|---|---|---|

## 타겟 종류

- **클릭 모드**: 구체(기본) 또는 풍선 — 맞히면 터지는 이펙트
- **트래킹 모드** (스트레이프 · 스무스 트래킹 · 타겟 스위칭): 움직이는 **사람 표적**(기본) 또는 클릭 타겟과 동일
  - 사람 표적은 바닥에 서서 움직이며, 체력바가 다 닳으면 터지지 않고 조용히 사라집니다
- 타겟 색상: 자동 / 무지개 / 9가지 단색

## 배경 테마 · 그래픽

미드나잇 그리드 · 라이트 랩 · 신스웨이브 · 보이드(미니멀) · 스카이 아레나

- **그래픽 품질 높음**: 네온 글로우(블룸), 환경 반사, 부드러운 그림자
- **그래픽 품질 낮음**: 후처리 없이 가볍게 (저사양 PC용)
- 인게임 HUD: 점수 카운트업, 콤보 카운터, 정확도 링 게이지, 킬피드, 마지막 5초 경고, 크로스헤어 히트 반응

## 루틴

- **인기 워밍업 5종** (5분): 그리드 → 식스 → 센터 리턴 → 마이크로 → 스트레이프 트래킹 — 에임 트레이너 커뮤니티에서 가장 많이 추천되는 구성을 참고
- **랭크 전 3분 워밍업**: 그리드 → 마이크로 → 스트레이프 트래킹
- **에임 베이직** (4분): 마이크로 → 센터 리턴 → 플릭 → 정밀 사격
- **밸런스 벤치마크** (5분): 식스 → 무빙 → 트래킹 → 스트레이프 → 스위칭
- **트래킹 집중 / 타겟 전환 집중**: 벤치마크에서 약점으로 나온 분야에 자동 추천

## 벤치마크 · 랭크 · 분석

- **벤치마크**: 8개 시나리오를 같은 조건(보통 · 45초 · 고정 시드로 매번 같은 배치)으로 플레이
- **티어**: 아이언 → 브론즈 → 실버 → 골드 → 플래티넘 → 다이아몬드 → 마스터 → 그랜드마스터 (시나리오별 + 종합)
  - 기준 점수는 점수 공식에서 추정한 **임시값**입니다 (`js/analysis.js`의 `BENCH_TOP`). 실제 플레이 데이터로 보정이 필요합니다.
- **약점 분석**: 결과 화면에서 방향별(좌/우/상/하) 처치 시간, 짧은/긴 플릭 비교, 오버플릭·언더플릭 경향, 트래킹 구간별 정확도와 피로도
- **추천**: 가장 약한 분야에 맞춘 루틴을 대시보드와 벤치마크 페이지에서 추천
- **기록 페이지**: 주간 플레이 수 · 평균 정확도 그래프, 시나리오별 최고/최근 기록과 추이

## 감도 찾기

루틴 페이지 또는 **설정 → 감도 → 감도 찾기**: 현재 감도의 0.7 · 0.85 · 1 · 1.2 · 1.4배로 각각 20초씩(순서는 무작위, 감도는 비공개)
센터 리턴 플릭을 플레이하고, 점수 곡선의 최고점으로 감도를 추천합니다. 결과에서 바로 적용할 수 있고, 이 테스트는 일반 기록에 섞이지 않습니다.

## 커스텀 시나리오

타겟 수 · 크기 · 거리 · 좌우/상하 범위 · 이동 속도 · 수명 · 트래킹 체력 · 플레이 시간을 조절해 직접 만들고,
**공유 링크**(`#s=...`)로 다른 사람에게 보낼 수 있습니다. 링크로 받은 설정은 허용된 범위로만 검증해서 가져옵니다.

## 기능

- **게임별 감도**: Valorant, CS2, Apex, Overwatch 2, Call of Duty, Fortnite, Rainbow Six Siege, cm/360 직접 입력
  - 게임마다 감도를 따로 저장하고, 게임을 바꾸면 그 게임의 감도가 적용됨
  - 모든 게임에 대해 "현재와 같은 회전량" 환산표 제공 + 원클릭 저장
  - 시야각이 고정된 게임(Valorant 103°, CS2 106.26°, OW2 103°)은 FOV 원클릭 적용
  - Chromium 계열에서는 마우스 가속 없는 raw 입력 사용
- **발사 키**: 마우스 왼쪽 클릭 + 추가 발사 키 1개 (키보드 아무 키 또는 우클릭/휠/옆 버튼) 지정 가능
- **수평 FOV** 설정 (70–120°), **크로스헤어** 커스터마이즈
- 시간(30/60/90초), 난이도(쉬움/보통/어려움) 선택
- 정확도, 평균 처치 시간, 반응속도, 최고 연속 등 결과 통계 + 최근 기록 그래프
- 대시보드(총 플레이, 최근 정확도, 연속 플레이 일수)와 시나리오별 기록 페이지
- 최고 기록 / 기록 히스토리 자동 저장 (브라우저 localStorage)
- **첫 실행 안내**: 언어 → 게임/감도/DPI → 벤치마크 또는 바로 시작
- **한국어 / English** 지원, **색약 모드** (적록색약 2종, 청황색약)
- **입력 진단 · DPI 측정**: 마우스 이벤트 빈도(Hz), 화면 주사율, raw 입력 여부 확인 + 자로 잰 거리로 실제 DPI 측정
- 지원 브라우저에서는 `pointerrawupdate` 이벤트로 입력 지연을 줄임
- **설치형 앱(PWA)**: 브라우저 주소창의 설치 버튼으로 앱처럼 설치, 한 번 접속하면 오프라인에서도 실행
- 오류 발생 시 로컬에 기록(외부 전송 없음) → 설정에서 복사 가능
- **기록 내보내기 / 가져오기 (JSON)**: 회사 PC ↔ 집 PC 기록 옮기기 (가져오면 기존 기록과 합쳐짐, 설정은 유지)
- 접근성: 키보드 포커스 표시, ESC로 창 닫기, OS "움직임 줄이기" 설정 존중
- 조작: 좌클릭(또는 지정 키) 사격 · `ESC` 일시정지 · `R` 즉시 재시작 · 결과 화면에서 `Enter` 다시 하기/다음 단계

## 테스트

```bash
npm ci              # 개발 도구 설치 (ESLint)
npm run lint        # 정적 검사: 중복 키 · 미정의 변수 · 이름 가림 등
npm test            # 단위 테스트: 감도 변환, 커스텀 검증, 랭크/분석, 번역 누락 검사
npm run test:e2e    # 브라우저 E2E: 온보딩, 전체 시나리오, 벤치마크 시드, 커스텀 공유, 설정 (playwright 필요)
```

GitHub Actions(`.github/workflows/ci.yml`)가 push마다 lint → 단위 테스트 → E2E → 배포 폴더 빌드를 실행합니다. 변경 내역은 [CHANGELOG.md](CHANGELOG.md)를 참고하세요.

## 사내 서버(IIS)에 배포

정적 파일만으로 동작하므로 IIS에 그대로 올리면 됩니다. 서버 쪽 코드나 DB는 필요 없습니다.

1. **배포 파일 준비** (둘 중 하나)
   - 저장소에서 `npm run build` → `dist/popshot` 폴더 생성 (Node.js 필요)
   - 또는 GitHub **Actions → CI → 최신 실행 → Artifacts → `popshot-web`** 다운로드 후 압축 해제
2. 서버의 `C:\inetpub\wwwroot\popshot` 같은 위치에 `popshot` 폴더 통째로 복사
3. IIS 관리자에서 **사이트 추가**(또는 기존 사이트에 **응용 프로그램/가상 디렉터리 추가**) → 실제 경로를 위 폴더로 지정
4. 브라우저에서 `http://서버이름/popshot/` 접속

참고

- 포함된 `web.config`는 **선택 사항**입니다 (없어도 게임은 동작). `.webmanifest` MIME 등록과 `index.html`/`sw.js` 캐시 끄기만 합니다.
  `web.config`가 hiddenSegments(다운로드 차단) 목록에 있는 건 IIS 기본 보안 설정이라 정상입니다.
- **HTTP 500.19 오류가 나면** 오류 페이지의 "오류 코드"를 확인하세요.
  - `0x80070005` (권한 부족): 폴더 → 속성 → 보안에서 **IIS_IUSRS**(및 IUSR)에 **읽기 및 실행** 권한 추가.
    다운로드한 zip을 풀어 옮긴 경우 권한이 상속되지 않아 자주 생깁니다.
  - `0x80070021` (구성 잠김) 또는 그 밖의 코드: `web.config`를 지우고 IIS 관리자 → **MIME 형식**에서
    `.webmanifest` → `application/manifest+json` 추가. (http에서는 앱 설치가 어차피 안 되므로 생략해도 됨)
- **http(사내 주소)에서도 정상 동작**합니다. 다만 브라우저 보안 정책상 https가 아니면 다음 기능은 자동으로 대체/생략됩니다.
  - 앱 설치 · 오프라인 실행(PWA): https에서만 가능 → http에서는 일반 웹페이지로 동작
  - 저지연 입력(`pointerrawupdate`): https에서만 → 일반 마우스 이벤트 사용 (차이는 미미)
  - 복사 버튼: 클립보드 API 대신 대체 방식으로 복사
- 외부 인터넷이 막혀 있어도 됩니다. 외부 리소스는 폰트(Pretendard CDN) 하나뿐이며, 막히면 맑은 고딕 등 시스템 폰트로 표시됩니다.
- 기록은 각 PC 브라우저에 저장됩니다 (동료끼리 순위 공유는 서버 기능이 필요).
- 회사 PC에서 그래픽이 느리면 **설정 → 배경 · 화면 → 그래픽 품질: 낮음**을 쓰세요.

## 상표 · 개인정보 · 라이선스

- 게임 이름(Valorant, Counter-Strike 2, Apex Legends, Overwatch 2, Call of Duty, Fortnite, Rainbow Six Siege)은
  감도 변환을 설명하기 위해서만 사용하며, 이 프로젝트는 각 상표권자와 관련이 없습니다.
- 모든 기록과 설정은 브라우저 localStorage에만 저장되며 서버로 전송되지 않습니다.
- 서드파티: three.js (MIT, `vendor/three.LICENSE`), Pretendard 폰트 (SIL OFL 1.1, CDN)
- 이 저장소 코드의 라이선스는 아직 정하지 않았습니다 (상용화 시 결정 필요).
