# 🎈 POPSHOT — 웹 FPS 에임 트레이너

브라우저에서 바로 하는 3D 에임 연습 게임입니다. 풍선을 플릭으로 터트리고, 트래킹하고, 반응속도를 측정하며 에임을 다듬을 수 있습니다.
빌드 과정 없이 정적 파일만으로 동작합니다 (Three.js 포함).

## 시나리오

| 시나리오 | 연습 포인트 | 설명 |
|---|---|---|
| 🎈 풍선 플릭 | 플릭 | 넓은 범위에 하나씩 뜨는 풍선. 빨리 터트릴수록 보너스 |
| 🟦 풍선 그리드 | 플릭 · 속도 | 5×5 격자에 풍선 3개. 연속 명중 보너스 |
| 🎯 마이크로 플릭 | 미세 조정 | 직전 위치 근처에 작은 풍선 |
| 🌀 풍선 트래킹 | 트래킹 | 좌클릭을 누른 채 움직이는 풍선 추적. 맞히는 동안 부풀다가 터짐 |
| ⚡ 반응속도 | 반응 | 10라운드, 나타나는 즉시 사격. 미리 쏘면 감점 |
| 🔭 정밀 사격 | 원거리 정밀 | 멀리서 점점 작아지다 사라지는 풍선 |
| 🎈 풍선 상승 | 타겟 전환 | 바닥에서 떠오르는 풍선을 천장 전에 처리. 점점 빨라짐 |

## 루틴

여러 시나리오를 연속으로 진행하고 마지막에 합계를 보여줍니다.

- **데일리 워밍업** (약 3분): 플릭 → 그리드 → 트래킹 → 마이크로
- **플릭 집중** (약 3분): 그리드 → 플릭 → 마이크로 → 정밀 사격
- **반응 & 추적** (약 2분): 반응속도 → 트래킹 → 풍선 상승

루틴은 `js/scenarios.js`의 `ROUTINES` 배열에 `[시나리오ID, 초]` 형태로 쉽게 추가할 수 있습니다.

## 기능

- **감도 맞추기**: Valorant / CS2·Apex / Overwatch 2 감도 또는 cm/360 직접 입력 + DPI → 실제 게임과 같은 회전량
  (Chromium 계열에서는 마우스 가속 없는 raw 입력 사용)
- **수평 FOV** 설정 (70–120°)
- **크로스헤어** 커스터마이즈 (색상, 길이, 두께, 간격, 점, 외곽선)
- 시간(30/60/90초), 난이도(쉬움/보통/어려움) 선택
- 정확도, 평균 처치 시간, 반응속도, 최고 연속 등 결과 통계 + 최근 기록 그래프
- 최고 기록 / 기록 히스토리 자동 저장 (브라우저 localStorage)
- 조작: 좌클릭 사격 · `ESC` 일시정지 · `R` 즉시 재시작 · 결과 화면에서 `Enter` 다시 하기/다음 단계

## 실행 방법

ES 모듈을 사용하므로 `index.html`을 파일로 직접 열지 말고 로컬 서버로 여세요.

```bash
python3 -m http.server 8000
# 또는: npx serve .
```

브라우저에서 http://localhost:8000 접속. PC + 마우스 환경(Chrome / Edge / Firefox)을 권장합니다.

## 웹에 배포 (GitHub Pages)

1. 저장소 **Settings → Pages**
2. **Source: Deploy from a branch**, 브랜치 선택 후 폴더 `/ (root)` 저장
3. 잠시 후 `https://<사용자명>.github.io/<저장소명>/` 에서 플레이

Netlify, Vercel, Cloudflare Pages 등 정적 호스팅 어디에 올려도 동작합니다.

## 구조

```
index.html          화면 마크업 (메뉴, HUD, 결과, 설정)
css/style.css       스타일
js/main.js          UI 연결, 루틴 진행, 결과 화면
js/game.js          게임 루프, 포인터 락 입력, 사격 판정, 상태 관리

js/targets.js       풍선 모델, 터지는 이펙트, 레이-구 히트 판정
js/world.js         렌더러, 카메라(FOV), 연습장
js/hud.js           HUD, 크로스헤어, 점수 팝업
js/audio.js         WebAudio 합성 효과음
js/storage.js       설정/기록 저장, 감도 변환
vendor/             three.js r170 (MIT)
```
