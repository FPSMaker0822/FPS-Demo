# 🎯 POPSHOT — 웹 FPS 에임 트레이너

브라우저에서 바로 하는 3D 에임 연습 게임입니다. 구체 · 풍선 타겟과 움직이는 사람 표적(트래킹)으로 플릭, 트래킹, 타겟 전환, 반응속도를 연습할 수 있습니다.
빌드 과정 없이 정적 파일만으로 동작합니다 (Three.js 포함).

## 타겟 종류

- **클릭 모드**: 구체(기본) 또는 풍선 — 맞히면 터지는 이펙트
- **트래킹 모드** (스트레이프 · 스무스 트래킹 · 타겟 스위칭): 움직이는 **사람 표적**(기본) 또는 클릭 타겟과 동일
  - 사람 표적은 바닥에 서서 움직이며, 체력바가 다 닳으면 터지지 않고 조용히 사라집니다
- 타겟 색상: 자동 / 무지개 / 9가지 단색

## 배경 테마 · 그래픽

미드나잇 그리드 · 라이트 랩 · 신스웨이브 · 보이드(미니멀) · 스카이 아레나

- **그래픽 품질 높음**: 네온 글로우(블룸), 환경 반사, 부드러운 그림자
- **그래픽 품질 낮음**: 후처리 없이 가볍게 (저사양 PC용)
- 인게임 HUD: 점수 카운트업, 콤보 카운터, 정확도 링 게이지, 킬피드, 마지막 5초 경고, 크로스헤어 히트 반응

## 루틴

에임 트레이너 커뮤니티에서 가장 많이 추천되는 구성을 참고했습니다 (과제는 모두 이 게임의 풍선 버전).

- **🔥 인기 워밍업 5종** (5분): 그리드 → 식스 → 센터 리턴 → 마이크로 → 스트레이프 트래킹
  — 에임랩에서 가장 많이 추천되는 Gridshot → Sixshot → Spidershot → Microshot → Strafetrack 조합
- **⏱️ 랭크 전 3분 워밍업**: 그리드 → 마이크로 → 스트레이프 트래킹
- **🎯 에임 베이직** (4분): 마이크로 → 센터 리턴 → 플릭 → 정밀 사격 (미세 조정 + 플릭 중심)
- **📊 밸런스 벤치마크** (5분): 식스 → 무빙 → 트래킹 → 스트레이프 → 스위칭
  — Voltaic 벤치마크식 분류(클릭 정적/동적 · 트래킹 정밀/반응 · 스위칭)

루틴은 `js/scenarios.js`의 `ROUTINES` 배열에 `[시나리오ID, 초]` 형태로 쉽게 추가할 수 있습니다.

## 기능

- **게임별 감도**: Valorant, CS2, Apex, Overwatch 2, Call of Duty, Fortnite, Rainbow Six Siege, cm/360 직접 입력
  - 게임마다 감도를 따로 저장하고, 게임을 바꾸면 그 게임의 감도가 적용됨
  - 모든 게임에 대해 "현재와 같은 회전량" 환산표 제공 + 원클릭 저장
  - 시야각이 고정된 게임(Valorant 103°, CS2 106.26°, OW2 103°)은 FOV 원클릭 적용
  - Chromium 계열에서는 마우스 가속 없는 raw 입력 사용
- **발사 키**: 마우스 왼쪽 클릭 + 추가 발사 키 1개 (키보드 아무 키 또는 우클릭/휠/옆 버튼) 지정 가능
- **수평 FOV** 설정 (70–120°), **크로스헤어** 커스터마이즈
- 시간(30/60/90초), 난이도(쉬움/보통/어려움) 선택
- 정확도, 평균 처치 시간, 반응속도, 최고 연속 등 결과 통계 + 최근 기록 그래프
- 대시보드(총 플레이, 최근 정확도, 연속 플레이 일수)와 시나리오별 기록 페이지
- 최고 기록 / 기록 히스토리 자동 저장 (브라우저 localStorage)
- 조작: 좌클릭(또는 지정 키) 사격 · `ESC` 일시정지 · `R` 즉시 재시작 · 결과 화면에서 `Enter` 다시 하기/다음 단계

## 실행 방법

ES 모듈을 사용하므로 `index.html`을 파일로 직접 열지 말고 로컬 서버로 여세요.

```bash
python3 -m http.server 8000
# 또는: npx serve .
```

브라우저에서 http://localhost:8000 접속. PC + 마우스 환경(Chrome / Edge / Firefox)을 권장합니다.

```

css/style.css       스타일

js/game.js          게임 루프, 포인터 락 입력, 사격 판정, 상태 관리

js/world.js         렌더러, 카메라(FOV), 연습장 배경 테마
js/hud.js           HUD, 크로스헤어, 점수 팝업
js/audio.js         WebAudio 합성 효과음
js/storage.js       설정/기록 저장, 감도 변환
vendor/             three.js r170 + 후처리/환경 애드온 (MIT)
```
